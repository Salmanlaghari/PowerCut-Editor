# CapCut / VN / KineMaster / YouCut Architecture Research

## Key UX/UI Patterns to Sync

### From CapCut (500M+ downloads)
1. **Real-time preview** — instant feedback, low-friction editing
2. **Drag-and-drop + gesture-driven trimming** — pinch to trim, drag to reorder
3. **Template-based editing** — pre-made templates for fast creation
4. **AI-powered features** — auto captions, background removal, auto-beat sync
5. **Non-destructive editing** — all edits are layered/previewable
6. **Minimal time import → edit → publish** — fast edit cycles
7. **Creative assets library** — large libraries of transitions, effects, filters, stickers, text
8. **Music library** — fast sound syncing
9. **Easy export + direct sharing** to TikTok, Instagram, YouTube

### From VN Video Editor
1. **Multi-track timeline** — video, audio, PIP, text, sticker layers
2. **No watermark export** (freemium model)
3. **Drafts auto-save** — projects saved automatically

### From KineMaster
1. **Multi-layer timeline** — up to 10+ layers (video, images, text, stickers, handwriting)
2. **Keyframe animation** — precise control over animations
3. **Chroma key / green screen** — background replacement
4. **Instant preview** — real-time rendering
5. **Asset store** — downloadable effects, transitions, fonts
6. **Precision speed control** — variable speed ramps
7. **Audio mixing** — multi-track audio with ducking

### From YouCut
1. **No watermark** — free exports with no branding
2. **Simple tool layout** — clean, focused tools
3. **Quick export presets** — social media aspect ratios
4. **Social-first** — optimized for Instagram/TikTok/YouTube
